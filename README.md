# Shizuku Lite

This project now works as a standalone, self-contained Android dashboard with a polished Material 3 interface and Jetpack Compose design.

## Features

- Standalone app experience with no Shizuku dependency
- Modern Material 3 dashboard UI
- Clean, premium card-based layout
- Notification status support with Android 13+ permission handling
- Lightweight and ready for further feature expansion

## Build

Open the project in Android Studio, install the required Android SDK, and build the `app` debug configuration. The debug APK is usually written to `app/build/outputs/apk/debug/`.

The app is intentionally independent and no longer requires the Shizuku client or provider library.
